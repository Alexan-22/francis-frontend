# Rutas implementadas

| Ruta | Estado |
| --- | --- |
| `/` | Inicio editorial con categorías |
| `/tienda` | Catálogo inicial, solicitud de búsqueda/página por confirmar |
| `/producto/:id` | Detalle y selección de talla según API tentativa |
| `/carrito` | Carrito por variante, persistencia local validada |
| `/login` | Inicio de sesión API tentativa |
| `/registro` | Registro API tentativa |
| `/checkout` | Bloqueado hasta tener contrato |
| `/mis-compras` | Información de indisponibilidad |
| `/admin` | Acceso restringido por rol |
| `/admin/vender` | Buscador POS; registro bloqueado hasta contrato |
| otras | Página 404 |
