Este módulo está preparado para incorporar la administración de usuarios de Francis Collection.

Antes de habilitar consultas y modificaciones de cuentas, debemos verificar los endpoints, DTO y permisos administrativos de auth-service a través del API Gateway.

Funcionalidades por integrar

  • Consultar las cuentas registradas.
  • Buscar usuarios por nombre o correo, si el backend admite esos filtros.
  • Consultar el estado de cada cuenta.
  • Activar o desactivar cuentas mediante operaciones administrativas autorizadas.
  • Gestionar permisos y roles únicamente cuando el backend lo permita.
